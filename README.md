# 🍕 Pizza Sales Analysis (SQL Project)

## 📖 Overview
This project analyzes pizza sales data to extract business insights using SQL. The queries focus on revenue analysis, sales trends, and top-selling pizzas.

## 📊 Dataset
- **Source:** `Data/`  
- **Columns:** Order ID, Pizza Name, Category, Quantity, Price, Order Date, etc.

## 🛠️ SQL Queries Used
- `PizzaSalesAnalysis.sql` → Solution Queries
## 🛠️ Presentation
- `PizzaSalesAnalysis_presentation-compressed.pdf`

## 📌 Key Insights
- Total revenue generated by pizza sales
- Best-selling pizza categories
- Sales trend over time (monthly/weekly)
- Average order value and customer spending patterns
